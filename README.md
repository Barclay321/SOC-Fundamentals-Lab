# SOC Fundamentals Lab – SIEM Investigation

## Objective
This lab simulates a Security Operations Center (SOC) workflow where alerts are investigated using SIEM-style logs.

## Scenario
A port scanning activity was detected from IP: 10.0.0.8 and required investigation using alert triage and log analysis techniques.

## Tools Used
- SOC simulation platform (TryHackMe)
- SIEM-style alert dashboard
- Log investigation interface

## Key Findings

- Source Host: NESSUS  
- Destination Host: JOE PC  
- Activity Type: Port Scanning  
- Severity: High  
- Source IP: 10.0.0.8  

## Skills Practiced
- Alert triage
- Log analysis
- Source/destination identification
- Incident investigation (5 W’s methodology)
- SIEM fundamentals

## Outcome
Successfully investigated and identified the source of a network port scanning alert using SIEM logs.
